# muslim-reminder
Free Daily Islamic Companion
A beautiful, free, single-file website with:
Today's Hijri + Gregorian date
Salah times (any city or GPS location)
Daily Quran verse (Arabic + English)
Daily authentic Hadith
Daily Dua
Suggested Dhikr
Daily Sunnah tip
Full Islamic months & sacred days reference
How to put it online (free)
Option 1 – Netlify (easiest, recommended)
Go to https://app.netlify.com
Drag & drop this entire folder (or just the index.html) onto the deploy area
Your site will be live in seconds at a free .netlify.app address
Option 2 – Vercel
Go to https://vercel.com/new
Upload the folder or connect a GitHub repo containing the index.html
Option 3 – GitHub Pages
Create a new public repository
Upload index.html
Enable GitHub Pages in Settings → Pages
Customisation
Change the default city in the input box (currently Cape Town)
All data is loaded from free public APIs (AlAdhan for prayer times & Hijri)
Completely static – no backend or database needed
Made with love for the Ummah. Free forever.
